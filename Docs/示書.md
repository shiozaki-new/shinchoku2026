# 示の書

## 目的

大阪展示会 思鳴会議室を、AIとオーナーが同じ現在地を参照できるHTMLページとリポジトリ構造として実体化する。

## 表示

- ヘッダー：名称とGitHubへの入口
- 現在地：認・思・鳴のどこまで確定したか
- 会議机：`Docs/会議項目.json` の全項目
- 鳴分岐：成立、思戻り、打切り
- 機械条件：開始時取得、正本、未確定停止、成立判定、GitHub帰属
- 次の一問：未確定の最上位項目
- 正本棚：認の書、思の書、鳴の書、示の書、継の記録

## 実装方針

- `index.html` 一枚でGitHub Pagesから配信できる
- 外部フレームワークとビルド工程を必須にしない
- 会議項目はJSONから読み、取得失敗時だけ同内容の最小フォールバックを表示する
- GitHub Issues APIからOpen件数と思鳴未確定件数を取得する
- JavaScriptが使えない場合も、目的、現在地、機械条件、次の一問は読める
- 320px以上の画面幅で横スクロールを発生させない
- キーボード操作と `prefers-reduced-motion` に対応する

## 応の判定

1. ローカルHTTP配信で `index.html` が200を返す
2. `Docs/会議項目.json` の項目が会議机へ表示される
3. AI引き継ぎ文をコピーできる
4. 正本棚の5リンクが実在するファイルを指す
5. `python3 Scripts/handover_guard.py` が成功する
