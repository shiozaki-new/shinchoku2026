# 認書

## 課題

大阪展示会に関する決定が会話履歴だけに残ると、AI・端末・セッションが変わった時点で現在地と判定条件が失われる。

## 観測できる不成立

- 次のAIが、決定済みか未確定かを質問し直す
- AIが既存画面や古い文書から展示会の目的を推測する
- 実装後に「何のために作ったか」が判定できない
- 同じ値がHTML、文書、Issueへ別々に書かれ、内容が食い違う
- 規則を読んだAIが、規則を通らず実装へ進める

## 現在の認

AI引き継ぎ基盤の必要性は存在し、実装対象として確定した。
大阪展示会そのものの成立条件は存在するが、値は未確定である。
